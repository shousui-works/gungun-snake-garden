# ぐんぐん ヘビの庭

エサを食べてぐんぐん育つ、子ども向けのブラウザゲームです。
スマホではヘビの周りをタップ、PCではクリック・矢印キー・WASDで操作できます。
広告・課金・ゲーム内ログイン・時間制限はありません。敵はコンピューターが動かします。

**[ブラウザで遊ぶ](https://shousui-works.github.io/gungun-snake-garden/)**

## 遊び方

1. 「やさしい・ふつう・むずかしい」を選び、「はじめる」を押します。
2. ヘビの頭の右側をタップすると右へ、上側をタップすると上へ曲がります。ドラッグでも方向を変えられます。PCではクリック・矢印キー・WASDも使えます。
3. 短いタップでも方向が変わり、指を離した後もその方向へ進みます。頭の真上へのタップは進行方向を保ちます。
4. りんご・バナナ・ぶどうを食べると成長します。大きく光るフルーツは経験値3です。ほっぺが膨らんで「ぱくっ！」と反応し、連続で食べると音が高くなります。
5. 自分より低レベルの「○」の敵は食べられます。「＝」の敵は同レベル。「！」の強い敵の頭に捕まると終了します。
6. はじめは保護されます（やさしい8秒、ふつう6秒、むずかしい5秒）。壁や自分の体に当たっても終了しません。
7. 右上のボタンで音の切り替え・一時停止ができます。Escでも一時停止・再開できます。
8. 結果画面の右上の「×」を押すと、終了したときのおにわとヘビを見られます。「結果にもどる」で結果画面に戻れます。Escでも切り替えられ、ニックネームやランキングの登録状態はそのまま残ります。

頭が画面外にいる敵も、体の縁と目印で強さを確認できます。強い敵は赤い縁と「！」、食べられる敵は緑の縁と「○」、同レベルは淡い縁と「＝」です。短く見えている体にも目印を付け、レベルアップすると表示が切り替わります。

最高レベル・難易度・表示範囲・音の設定・おにわのお花・ランキング用のニックネームとランダムキーを、そのブラウザに保存します。保存できなくても遊べます。
画面が隠れたり、別のタブへ移ったときは自動で一時停止します。

## 選べる難易度

| 難易度 | 速さ | 敵の数 | はじめの保護 |
| --- | --- | --- | --- |
| やさしい | ゆったり | 3〜4体 | 8秒 |
| ふつう | ほどよい | 4〜5体 | 6秒 |
| むずかしい | これまでの速い版 | 4〜6体 | 5秒 |

初回は「ふつう」で、次回は最後に選んだ難易度になります。「やさしい」は強い敵の出現を控えめにし、追いかける距離と時間も短くしています。
一時停止・終了画面の「むずかしさを変える」から選び直せます。選び直すとレベル1からの新しいプレイになりますが、お花は残ります。最高レベルは難易度共通です。

移動の速さは難易度で変わります。どの難易度でも、自分と普通の敵は同じ速さで、レベルによる加速はありません。レベルが上がると体が大きくなり、食べられる敵が増えます。旋回も速さに合わせて調整しています。おたからヘビはどの難易度でも追いつけるよう、少し遅めです。

## おたからヘビと育つおにわ

- 遊び始めて8秒ほどで、小さな金色のおたからヘビが近くに現れます。近づくと逃げますが、プレイヤーより遅く、レベル1でも捕まえられます。頭でも体でも捕まえられ、敵のように襲ってきません。
- 捕まえると、りんご・バナナ・ぶどうが8個飛び出します。着地したフルーツを食べると経験値になります。敵はこのおたからフルーツを食べません。
- お宝の経験値は、捕まえた時の自分のレベルに合わせて増えます。通常は1レベル分の約半分、最低10経験値です。Lv.50なら合計52、Lv.100なら102経験値。果物は8個のままで、1個ずつの経験値が増えます。捕まえた瞬間には加算せず、回収中にレベルが上がっても各果物の価値は変わりません。
- 出現時に15％の確率で「大あたり」のお宝ヘビになります。金色の体に宝石の模様と頭飾り、紫色の光、「大あたり」の表示が付き、画面外の矢印も宝石になります。報酬は通常の2倍で、後半は約1レベル分。Lv.50なら104、Lv.100なら204経験値です。果物にも宝石の目印が付き、出現時と捕獲時は特別な音が鳴ります。
- おたからヘビが画面の外へ進むと、小さな金の矢印が居場所を示します。逃しても終了せず、しばらくするとまた現れます。
- 食べた場所にお花が咲きます。りんごはピンク、バナナは黄色、ぶどうは紫。おたからを捕まえた場所には金色のお花が咲きます。
- お花は小さく淡い色で地面になじませ、果物には明るい縁取りを付けています。果物が見つけやすく、花と見分けやすい表示です。
- お花は再開始・ページの再読み込み後も残ります。お花の数と捕まえたおたからの数は、一時停止や結果の画面で見られます。

お花は600本まで保存し、それ以降は古い花から植え替えます。通常のエサ80個に加え、おたからフルーツは16個まで。着地後22秒経つと消えるので、遊び続けても増え続けません。

## Lv.100まで育つとへんしん

全部で23段階の姿に変わります。Lv.3・5・8の変身を引き継ぎ、Lv.10以降は5レベルごとに新しい姿になります。

| --- | --- | --- | --- |
| 1 | むらさき | 50 | ほし |
| 3 | みずたま | 55 | オーロラ |
| 5 | お花ぼうし | 60 | ぎんのよろい |
| 8 | にじいろ | 65 | ロケット |
| 10 | いちご | 70 | うちゅう |
| 15 | みつばち | 75 | キャンディ |
| 20 | うみ | 80 | きんの王さま |
| 25 | ゆき | 85 | ドラゴン |

| 35 | メロン | 95 | フェニックス |
| 40 | とら | 100 | にじの王さま |
| 45 | エメラルド | | |

色、体の模様、頭の飾りが変わります。星や花などの模様は体の節で隠れないように描き、Lv.100は虹色の体・金の星と輪・羽付き王冠です。次の変身レベルはゲーム画面の右下に表示します。変身時には名前を表示し、複数の変身レベルを一度に超えた場合は最後の姿を知らせます。長い名前も小さい画面に収まるよう調整します。

見た目の変身で速度や敵との強弱は変わりません。Lv.100より上は最後の姿を保ちます。レベルによる体の大きさや長さの上限、難易度ごとの速さは従来の設定を使います。

画面いっぱいにおにわを広げ、上下の操作・情報バーをなくしました。遊んでいる間は右上に音と一時停止だけを表示します。自分のヘビの頭の近くに、レベルと次のレベルまでの小さな経験値バー・経験値の数を表示します。あと少しでレベルアップするときはバーが金色になります。画面の端では表示位置を調整して、バーが切れないようにしています。経験値は一時停止メニュー、最高レベルは開始メニューでも確認できます。ヘビとフルーツの表示倍率は画面の幅と高さに合わせて調整し、プレイヤーの旋回を速めています。カメラが端へ移動しても、画面上の頭の位置を基準に操作できます。

## 画面に合わせた表示範囲

初回は「広く見る」です。画面の短い辺に合わせて表示倍率を自動調整し、狭いスマホや横向きの画面では少し引いて表示します。小さい画面でもヘビ・フルーツが小さくなりすぎないよう倍率の下限を設けています。

一時停止メニューの「見える範囲」で「広く見る／大きく見る」を切り替えられます。「大きく見る」は自動調整した倍率を約1.35倍にして、ヘビやフルーツを見やすくします。選択はそのブラウザに保存し、再開始・再読み込み後も使います。レベルやプレイの進行はリセットしません。

経験値バー、敵とおたからのレベル表示、体の強さの目印、「ぱくっ！」などの文字は倍率で小さくなりません。メニューのボタンは48px以上を維持します。横向きで高さが低い場合は、一時停止メニューを左右に分け、見える範囲と再開ボタンを同時に確認できます。回転やサイズ変更の後も、頭の画面上の位置に合わせてタップの方向を判定します。

## みんなのランキング

開始・一時停止・終了メニューの「みんなのランキング」から、難易度別の上位20件が見られます。同じレベルでは経験値の多い方が上になり、同点は同順位です。自分の自己ベストと順位は、上位20件の外でも確認できます。遊んでいる画面に情報を増やしません。

名前の下と自分の自己ベスト欄に、登録日時を `2026/10/17 18:25` の形式・日本時間で表示します。既存の記録にも保存済みの日時を表示し、自己ベストを更新すると日時も更新します。低い記録や同点の再登録、ニックネームの変更では元の日時を保ちます。

ゲーム終了時にニックネーム（1〜12文字）を入れて「とうろく」を押すと、みんなに公開されます。ログインやメールアドレスは不要です。1つのブラウザにつき、難易度ごとの自己ベストを1件だけ保存します。低い記録を送ってもベストは下がりません。ランキング画面から自分の記録を消すこともできます。

高レベルの敵や大当たりのお宝で短時間に多くの経験値を得た場合も登録できます。Lv.100を超えても登録可能です。登録に失敗しても結果画面が残っていれば、「もう一度」から同じ記録を再送できます。登録前にページを閉じると、その回の未登録記録は失われます。

順位や記録は共通DBから取得し、端末をまたいで共有します。ブラウザを再読み込みしても残ります。ブラウザの保存データを消すと新しいプレイヤーになるため、以前の記録の更新・削除はできなくなります。通信できないときもゲームは遊べ、登録・読み込みに失敗した場合は画面で知らせます。

保存サービスのソースは[`ranking-service/`](ranking-service/)です。ゲームの公開URLはこれまでと同じGitHub Pagesです。記録保存サービスはSitesで別途公開します。気軽に競うためのランキングで、クライアント改造による不正を完全に防ぐものではありません。

## 手元で動かす

Node.js 24を使います。追加パッケージのインストールは不要です。

```sh
npm run dev
```

同じ端末のブラウザで、表示された `http://127.0.0.1:4173` を開きます。

```sh
npm test
npm run build
```

`dist/` が配信用のゲームです。標準のCanvas・JavaScript・CSSで実装し、ゲーム自体は外部サービスや素材の読み込みに依存しません。共有ランキングだけはSitesの記録保存サービスへ接続します。
`npm run build` はJavaScriptの構文を確認し、1ファイルで開ける `release/snake-garden.html` も作ります。
HTML版は保存してPCのChromeやSafariで開けます。スマホのファイル表示アプリでの動作は未確認です。

## GitHubで更新する

`main` に変更を送ると自動チェックが走ります。GitHub Pagesの更新も自動で行います。

### 独自ドメインへの移行

移行先は `https://game.ludora-base.com/` です。共有ランキングはこのURLからの接続に対応しています。公開URLの切り替えは、GitHub Pagesのカスタムドメイン設定とSquarespaceのDNS設定を合わせて行います。

| Squarespaceの項目 | 値 |
| --- | --- |
| ホスト | `game` |
| タイプ | `CNAME` |
| データ | `shousui-works.github.io` |
| TTL | 既定値 |

GitHub Pagesのカスタムドメインを `game.ludora-base.com` に設定してから上記レコードを保存し、DNSの反映とHTTPS証明書の発行後にHTTPSを強制します。Actionsで配信しているため、`CNAME`ファイルは不要です。既存のサイトやメールのDNSレコードは変更しません。

ブラウザの保存領域は公開元のURLごとに分かれます。新しいドメインでは、お花・設定・ランキングのプレイヤーキーは自動で引き継がれません。公開済みのランキング記録は残ります。

- 速度、エサの数、敵の数、色：[`dist/game/config.js`](dist/game/config.js)
- レベルアップのルール：[`dist/game/rules.js`](dist/game/rules.js)
- 移動・敵・衝突：[`dist/game/simulation.js`](dist/game/simulation.js)
- 見た目：[`dist/style.css`](dist/style.css)、[`dist/game/renderer.js`](dist/game/renderer.js)
- HTML版の生成：[`scripts/build-standalone.mjs`](scripts/build-standalone.mjs)
